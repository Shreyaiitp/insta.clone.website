# insta.clone.website
This is a Insta website clone. I made it during Git tutorial
This project is a simple website inspired by Instagram. I created it while following a Git tutorial to practice the basics of version control and learn how to manage a project with Git.

The tutorial helped me get familiar with creating a repository, tracking changes, and saving updates as commits. This project also gave me a chance to experiment with building a website and organizing its files.

This is a learning project, so it may not include all the features of Instagram. It serves as a starting point for practicing web development and Git.
